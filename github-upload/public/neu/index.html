      KI-Einstellungen

      Deine KI

      Wähle, welche KI im Gespräch hilft und die Mindmaps erstellt. Der Schlüssel wird nur in diesem Browser gespeichert.

      Anbieter

      Ohne Schlüssel erstellt Flow Valu eine einfache Mindmap direkt im Browser. Für den echten Betrieb gehört der Schlüssel später auf den Server.

      Anleitung

      So testest du die KI

      01API-Schlüssel besorgen

      Einer reicht — ChatGPT oder Claude.

      • ChatGPT: auf platform.openai.com anmelden, unter „Billing“ etwas Guthaben aufladen (ein paar Euro reichen lange), unter „API keys“ einen neuen Schlüssel erstellen. Er beginnt mit sk-….
      • Claude: auf console.anthropic.com anmelden, unter „Billing“ Guthaben aufladen, unter „API Keys“ einen Schlüssel erstellen. Er beginnt mit sk-ant-….

      Ein ChatGPT-Plus- oder Claude-Pro-Abo reicht nicht — die Schnittstelle wird separat abgerechnet.

      02Seite richtig öffnen

      Kamera und Mikrofon funktionieren nicht, wenn du die Datei nur doppelklickst. Die Seite muss über HTTPS oder localhost laufen.

      • Ordner site entpacken.
      • Im Ordner ein Terminal öffnen und python -m http.server 8000 eingeben (oder npx serve).
      • In Chrome http://localhost:8000 öffnen.
      03KI verbinden
      • Oben den Anbieter wählen und den Schlüssel einfügen.
      • Auf Verbindung testen klicken. Erscheint „Verbindung funktioniert“, auf Speichern klicken.
      • Bei einem Modell-Fehler ein aktuelles Modell eintragen, z. B. gpt-4o-mini oder ein aktuelles Claude-Modell aus der Anthropic-Konsole.
      04Im Gespräch testen — auch allein
      • Ein zweites Chrome-Fenster im Inkognito-Modus mit derselben Adresse öffnen und dort ein zweites Konto anlegen.
      • In beiden Fenstern denselben Begriff wählen, z. B. „Vertrieb“ — die beiden verbinden sich.
      • KI-Feld: Reiter „KI“ öffnen und eine Frage stellen. Die Antwort erscheint in beiden Fenstern.
      • Mitschrift: Reiter „Mitschrift“ → „Mitschrift anfragen“, im anderen Fenster zustimmen, dann eine Weile sprechen.
      • Mindmap: „Mindmap & PDF erstellen“ klicken oder das Gespräch beenden. Unter Notizen erscheint die Notiz — dort „Als PDF speichern“.
      05Damit es nicht hakt
      • Der Schlüssel wird pro Fenster gespeichert. Für den Test reicht er in dem Fenster, in dem du die KI fragst und die Mindmap erstellst.
      • Chrome oder Edge nutzen — sonst funktioniert die Mitschrift nicht.
      • Den Schlüssel mit niemandem teilen. Diese Version ist zum Testen gedacht.
